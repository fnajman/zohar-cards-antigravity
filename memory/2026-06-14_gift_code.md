# Système de Code Cadeau (v1.1.13 / v0.53)

## Résumé des Changements Actuels
- **Backend API (Xano)** : Intégration d'un endpoint `GET /bonus/coupon/{coupon_code}` permettant de récupérer les propriétés dynamiques d'un coupon (crédit accordé, date d'expiration).
- **Frontend State** : Le code cadeau n'est plus vérifié "en dur" (anciennement `BONUS03`). Désormais, `applyGiftCode(code)` appelle l'API Xano de façon asynchrone via `src/services/bonusApi.ts`.
- **Logique de Validation** :
  1. Le frontend vérifie que le code n'est pas déjà dans le tableau `usedGiftCodes` du profil de l'utilisateur (sauf pour les admins/contribs).
  2. Le frontend interroge l'API Xano.
  3. L'application vérifie si la `expiration_date` (retournée par Xano) est dépassée par rapport à la date locale de l'appareil.
  4. Si tout est valide, le `credit` retourné par Xano est ajouté au profil utilisateur et Xano est mis à jour.
- **Interface Utilisateur** : `SettingsScreen.tsx` gère un état asynchrone (`isSubmittingGiftCode`) avec un spinner de chargement et verrouille les inputs le temps de la requête.
- **Internationalisation** : Traductions mises à jour pour supporter les messages d'expiration spécifiques (`gift_code_expired`) et le compte dynamique de crédits ajoutés (`gift_code_success`).
