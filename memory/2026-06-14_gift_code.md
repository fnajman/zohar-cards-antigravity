# Système de Code Cadeau (v0.19)

## Résumé des Changements
- **Frontend State** : Ajout d'une gestion locale et persistante des codes cadeaux dans `useStore.ts` via Zustand. La fonction `applyGiftCode(code)` vérifie la validité du code, gère les états "déjà utilisé" ou "invalide/expiré", et crédite le compte utilisateur de 3 crédits si succès.
- **Logique** : Pour le moment, seul le code "BONUS03" est actif en dur dans le code (comme demandé pour la première étape avant l'intégration Xano).
- **Interface Utilisateur** : Ajout d'une section "Code cadeau" dans la page des Paramètres (`SettingsScreen.tsx`), qui affiche un champ de saisie (`input`) et un bouton de soumission. Des messages de feedback (succès ou erreur) s'affichent avec des styles de couleurs adaptées au design de l'application (vert sombre / rouge sombre).
- **Internationalisation** : Ajout des clés de traduction liées aux codes cadeaux dans `en/translation.json` et `fr/translation.json`.

## Fichiers Modifiés
- `src/store/useStore.ts`
- `src/screens/SettingsScreen.tsx`

- `src/locales/en/translation.json`
