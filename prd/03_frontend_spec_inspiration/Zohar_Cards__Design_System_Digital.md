Zohar Cards — Design System Digital

Adaptation spécifique à l’app de tirage

Purpose
This document adapts the Zohar Cards Design System and Print Charter into a mobile‑first digital experience dedicated to the act of drawing letters.

The app is not a game, not a tarot app, not a decision engine.
It is a ritualized interface designed to frame a symbolic moment.

⸻

1. Digital Philosophy

1.1 Core Principle

The interface must disappear behind the gesture.

The user should feel:
	•	guided, not driven
	•	accompanied, not instructed
	•	calm, not stimulated

The app does not accelerate — it slows down.

⸻

1.2 UX Posture

Axis	Position
Authority	Very low
Guidance	Structural only
Emotion	Neutral, contained
Tempo	Slow
Interaction	Minimal


⸻

2. App Structure (Macro)

2.1 Allowed Screens Only
	1.	Opening / Stillness screen
	2.	Intention screen (optional)
	3.	Draw gesture screen
	4.	Letter reveal screen
	5.	Contemplation screen
	6.	Optional second / third draw
	7.	Closing / return to silence

No dashboards. No feeds. No gamification.

⸻

3. Color & Material (Digital)

3.1 Backgrounds

Primary:
	•	Deep night blue (#0E0F1A)

Secondary:
	•	Parchment ivory (#F5F1E8)

Rules:
	•	One background per screen
	•	No gradients (except subtle grain texture)

⸻

3.2 Texture

Allowed:
	•	paper grain
	•	mineral noise

Opacity ≤ 6%

Never:
	•	blur effects
	•	glassmorphism

⸻

4. Typography (App)

4.1 Latin Text

Usage hierarchy:
	1.	Micro‑guidance (very short)
	2.	Labels
	3.	Metadata

Rules:
	•	short sentences only
	•	neutral verbs
	•	no poetic overload

⸻

4.2 Hebrew Letter Rendering

The Hebrew letter:
	•	occupies the visual center
	•	appears alone
	•	fades in slowly (300–500 ms)

Never:
	•	animated transforms
	•	rotation
	•	glow

⸻

5. Interaction & Gesture

5.1 Draw Gesture

Allowed gestures:
	•	tap and hold
	•	slow swipe
	•	still press (2–3 seconds)

Forbidden:
	•	shake
	•	random animation
	•	slot‑machine metaphors

⸻

5.2 Haptic & Sound

Haptic:
	•	single, soft vibration

Sound (optional):
	•	low‑frequency tone
	•	very short

Silence is default.

⸻

6. Letter Reveal Screen

Structure:

[ silence ]

[ Hebrew Letter ]

[ transliteration – optional ]

[ archetypal word ]

Rules:
	•	no explanation at reveal
	•	no interpretation yet

⸻

7. Contemplation Screen

Purpose:

Let the user stay with the letter.

Elements allowed:
	•	one reflective sentence
	•	optional breathing cue
	•	optional body anchor (very neutral)

Never:
	•	advice
	•	outcome suggestion

⸻

8. Multiple Draws (Critical)

Rules:
	•	maximum 3 letters
	•	each new draw must be explicit
	•	no automatic chaining

Between draws:
	•	pause screen
	•	user confirmation

⸻

9. Ethical UX Guardrails (Digital)

The app must ALWAYS:
	•	ask questions, not answer them
	•	reframe interpretation as personal
	•	avoid directional language

Forbidden copy:
	•	“this means”
	•	“you should”
	•	“this indicates that”

⸻

10. Microcopy Examples

Allowed:
	•	“Take a moment before drawing.”
	•	“What does this letter awaken?”
	•	“Would you like to stay with this symbol?”

Avoid:
	•	“Your answer is…”
	•	“This card tells you…”

⸻

11. Accessibility & Inclusion
	•	readable contrast
	•	no color‑only meaning
	•	slow motion tolerances

⸻

12. LLM — APP GENERATION PROMPT

You are designing a mobile application for Zohar Cards.

This app frames a symbolic draw, not a prediction.

Design rules:
- minimal screens
- slow rhythm
- large margins
- one Hebrew letter per screen

UX ethics:
- never suggest decisions
- never interpret for the user
- always preserve silence and choice

Goal:
Create an interface that supports contemplation, not answers.


⸻

13. Final Digital Principle

If the user feels guided, you went too far.

The app must hold space — nothing more.
